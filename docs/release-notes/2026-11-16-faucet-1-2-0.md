# Unique nicknames are live on Sepolia

`ChipFaucet` on Sepolia now runs 1.2.0, so nicknames are unique, ignoring letter case. The nicknames players already had are reserved for them.

## Changes

- Upgraded the `ChipFaucet` proxy `0xfdB7…A2DC` from 1.1.0 (`0xc027…49ac`) to 1.2.0 (`0x1E16…9C85`), verified on Etherscan.
- Ran `reserve-nicknames`: it found 3 players with nicknames from block 12,112,056 to 12,148,360, reserved all 3, and found no duplicates.
- Updated `deployments/sepolia.json`, `.openzeppelin/sepolia.json` and the Sepolia table in `docs/contracts.md`. The docs now note that the task needs an RPC allowing 5,000-block log searches.

## Removed

- Nothing.

## Verification

- Before the upgrade, read-only: version 1.1.0 at the recorded implementation, the signer is the owner, not paused, and `validate-layout:sepolia` says it's a safe upgrade.
- After: version 1.2.0 at `0x1E16…9C85`, owner unchanged, not paused, and `isNicknameTaken` answers. Each of the 3 reserved names, typed in capitals, is taken for anyone else and free for its holder.
